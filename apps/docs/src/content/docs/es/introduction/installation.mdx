Moderno se instala como paquetes npm. Cada framework tiene su propio paquete; todos comparten
`@moderno-ui/tokens` (las variables CSS) y el CSS de componentes.

## 1. Instala el paquete de tu framework

<Tabs syncKey="framework">
<TabItem label="React">
```sh
npm install @moderno-ui/react
```
</TabItem>
<TabItem label="Vue">
```sh
npm install @moderno-ui/vue
```
</TabItem>
<TabItem label="Svelte">
```sh
npm install @moderno-ui/svelte
```
</TabItem>
<TabItem label="Solid">
```sh
npm install @moderno-ui/solid
```
</TabItem>
</Tabs>

El paquete trae como dependencias `@moderno-ui/tokens`, `@moderno-ui/styles` y las máquinas de Zag
que necesita. No instalas Zag por separado.

## 2. Importa los estilos una vez

En el punto de entrada de tu app, importa los tokens y el CSS de componentes. Los tokens
definen las custom properties `--md-*`; el CSS de componentes define las clases `md-*`. Ambos
se re-exportan desde el paquete de tu framework, así que no necesitas instalar
`@moderno-ui/tokens` por separado.

<Tabs syncKey="framework">
<TabItem label="React">
```ts
import '@moderno-ui/react/tokens.css'
import '@moderno-ui/react/styles.css'
```
</TabItem>
<TabItem label="Vue">
```ts
import '@moderno-ui/vue/tokens.css'
import '@moderno-ui/vue/styles.css'
```
</TabItem>
<TabItem label="Svelte">
```ts
import '@moderno-ui/svelte/tokens.css'
import '@moderno-ui/svelte/styles.css'
```
</TabItem>
<TabItem label="Solid">
```ts
import '@moderno-ui/solid/tokens.css'
import '@moderno-ui/solid/styles.css'
```
</TabItem>
</Tabs>

## 3. Elige el tema

El tema se controla con el atributo `data-theme` en el `<html>` (o cualquier ancestro):

```html
<html data-theme="dark">
  <!-- … -->
</html>
```

Moderno es **dark-first**; `data-theme="light"` re-mapea los roles semánticos. Para re-skin
total, sobrescribe las variables `--md-*` en tu propio CSS — los componentes no cambian.

## 4. Usa un componente

<TabItem label="React">

</TabItem>

</TabItem>
<TabItem label="Solid">

export function App() {
